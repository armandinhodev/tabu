# Flujo ODD

1. Explorá solo las áreas necesarias del repo y detectá restricciones.
2. Prepará una ficha: objetivo, fuera de alcance, criterios de aceptación, tareas pequeñas y checks.
3. Si el plan revela alto impacto, pasá a SDD y esperá aprobación. Si falta una decisión relevante, preguntá en lugar de adivinar.
4. En Build implementá por partes, verificá cada cambio y compará el diff final con los criterios. Para cambios relevantes, pedí revisión independiente.
