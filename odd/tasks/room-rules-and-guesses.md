# Room rules and typed guesses
Objective: configure taboo-word count and turn duration; make typed guesses server-verified with per-player visibility and feedback.
Branch: `feat/tabu`. Delivery: `ask-on-risk` (forecast ~1,400 authored lines; chain strategy pending). Runner: `pnpm exec vitest run`, `pnpm lint`, `pnpm typecheck`.

## Specs

- **S1 — Taboo count.** "En la configuración de la sala, se tiene que poder setear la cantidad de palabras prohibidas por ronda (minimo 1 palabra, hasta 6) por defecto 4." Clarification: "dale" to completing seed cards to six; one configured count applies per card. Preserve pre-existing game snapshots when extending settings. Check 1, 4, 6 and invalid options across creation, persisted snapshots and turn views.
- **S2 — Duration.** "El tiempo por turno tiene que ser de 30 | 60 | 90 | 120." Check UI, payload validation, default and deadline at each allowed duration; reject removed 45 for new rooms without breaking historic snapshots.
- **S3 — Guesses.** "El jugador que tiene que adivinar tiene que escribir su respuesta y se tiene que verificar con la respuesta de la base de datos de forma insensitiva, si hay match se le da el punto" and "pero luego de adivinar en la caja donde va escribir se le va mostrar que acertó. Esa caja es como un chat con el juego donde el solo puede interactura". Compare typed input with the authoritative active card in memory, originally loaded from DB; normalize using the established word helper. A wrong answer must not award a point or end the turn (assumption). Check role authorization, server payload, output, score and unchanged game state on rejection.
- **S4 — Visibility.** "La palabra que va adivinar se debería mostrar a todos menos al que tiene que adivinar" and "Que la palabra solo se le muestre al que describe, el al resto de su equipo no se le debe mostrar, y porsupuesto a todo el otro equipo se le tiene que mostrar la Palabra adivinar y las prohibidas". Active-team players except the descriptor do not receive the target word in any server event, including reconnect; the descriptor and rivals do. The active guesser sees no taboo list as a clue (assumption). Check raw wire payloads for all roles.
- **S5 — Private notices.** "también va servir para notificar cuando la carta se pase porque dijo una palabra prhibida debido a que alguien del otro equipo la presionó". The private game chat for active guessers displays their own answer and success/failure plus the rival taboo penalty notification. Check real-time event behavior and per-turn reset.
- **S6 — Seed safety.** "dale, pero para eso tendríamos que truncar la db y rehacer el seed no?" The existing `seedDecks` upserts by name; add words to the existing 240 seed cards locally, with no database execution, truncation or remote operation. Check content validation and idempotency. Any database modification requires separate authorization.
